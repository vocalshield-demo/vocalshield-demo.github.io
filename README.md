# VocalShield — Anonymous Supplementary Material

This repository contains supplementary material for anonymous peer review.

## Contents

- One combined desktop and Jetson Orin Nano demonstration, 54.4 seconds
- Four LibriTTS samples compared across Original, seven baselines, and VocalShield
- Original and protected speech cloned with ten voice-cloning systems
- A machine-readable audio manifest with checksums

All audio is mono, 16-bit PCM WAV. Each method retains its native sampling rate
and produced duration. The page has no analytics, cookies, external fonts,
or third-party media embeds.

## Local preview

Run `node scripts/serve.cjs`, then open `http://127.0.0.1:4173/`.
